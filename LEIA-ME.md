# acertoapp.com.br

Site do Acertô!, publicado no GitHub Pages: início, suporte, termos de uso e política de privacidade.

- `fontes/termos.md` e `fontes/privacidade.md`: o texto dos documentos legais (mesmo conteúdo dos Docs).
- `gerar.py`: monta as páginas HTML a partir das fontes. Depois de mudar um texto, rode
  `python3 gerar.py` (precisa de `pip3 install markdown`) e versione.
- Para mostrar o CNPJ nas páginas, preencha `CNPJ = "..."` no topo do `gerar.py` e rode de novo.
- `CNAME`: o domínio do GitHub Pages. Não apague.

Endereços para a App Store Connect:

- Suporte: https://acertoapp.com.br/suporte/
- Política de privacidade: https://acertoapp.com.br/privacidade/
- Termos de uso (EULA próprio, opcional): https://acertoapp.com.br/termos/
